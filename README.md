# EduFlow AI

</div>

## 빠른 시작

```bash
# 1. 저장소 클론
git clone https://github.com/eduflow-team/ai.git
cd ai

# 2. 환경 변수 파일 생성
cp .env.example .env

# 3. Langflow 실행
docker compose up -d

# 4. 브라우저 접속
open http://localhost:7860
```
